Git Clone as the "Download" button of Github. 
While a regular download just gives you a snapshot of the current files, a clone gives you the entire history, every branch, and every commit ever made in that project.

Creates a complete local copy of a remote repository

From a remote server (GitHub, GitLab, Bitbucket) to a new directory on your local system

git clone <url-of-repo>


When you run git clone, Git does four things automatically:

Creates a folder with the project name.

Initializes a local .git folder inside it.

Downloads all the data (files and history).

Sets up the "Remote": It automatically names the source URL as origin, so you’re ready to push and pull immediately.

HTTPS: git clone https://github.com/user/repo.git (Asks for your GitHub username/token).

SSH: git clone git@github.com:user/repo.git (Uses that ed25519 key you set up!).
