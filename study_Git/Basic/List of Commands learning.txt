###

In Git, HEAD is a pointer that tells Git which commit you are currently working on. 
Think of it as a "You Are Here" marker on a map of your project's history.
Most of the time, HEAD doesn't point directly to a commit; instead, it points to a branch reference. 
When you switch branches, HEAD moves to point at the new branch

bash-3.2$ git log -n 1
commit fb4765da48dbd52a3e43c1cbb802db0e3fb5599b (HEAD -> creating-new-branch)
Author: GurpreetThind <thind.cse@gmail.com>
Date:   Sun Mar 29 22:53:09 2026 -0400

On a Branch ---> New commits are saved to that branch automatically.

Detached HEAD ---> You can look at old code, but new commits won't belong to any branch and might be lost.

 Understand .gitignore


 ##############

 There are files that are required for your project but do not need Version Management via Git 

 Those files and folders can be ignored via .gitignore

 if you want to ignore all files but dont want to ignore a certain file then write 

 *.log
 !test.log

 test.log will not be ignored although it ends with .log

ignore a subfolder and its content with 

folder_name/*
